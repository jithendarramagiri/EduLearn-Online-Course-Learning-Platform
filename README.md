## 🌟 Detailed Feature Breakdown

- 🤖 **Interactive EduAI Study Companion & Micro-Quiz Sandbox**:
  - Floating 24/7 AI tutor accessible on every page.
  - **Concept Explainer**: Breaks down complex topics (React 19 Server Actions, Transformers, RAG, Zero-Trust security) into crisp bullet points.
  - **Interactive Quiz Sandbox**: Dynamic multiple-choice questions with instant scoring, answer explanations, and score tracking.
  - **Interview Lab**: Real FAANG architectural questions with guidance.

- 🧭 **AI Career Compass & Interactive Skill Matrix (`/career-compass`)**:
  - 6 High-Income tracks: Full-Stack GenAI Architect, Cloud & DevOps Platform Engineer, Cyber Defense Specialist, Full-Stack Web Architect, Data Science Lead, and Mobile App Architect.
  - **Interactive Visual Roadmap**: Phase 1 Foundation &rarr; Phase 2 Core &rarr; Phase 3 Advanced &rarr; Phase 4 Capstone.
  - **Live Salary & ROI Slider**: Real-time salary projection based on 0 to 6+ years of experience in INR (LPA) or USD ($).
  - **1-Click Track Enrollment**: Automatically registers all 4 curriculum courses straight into the student's My Learning hub.

- 🛡️ **Public Certificate Verification Portal (`/verify`)**:
  - Allows employers, recruiters, and students to enter any Certificate ID (e.g. `EDU-2026-REACT-8842`).
  - Displays authenticated student name, grade (e.g. 98% Distinction), issue date, lead instructor, curriculum competencies, and 256-bit cryptographic signature.
  - Built-in print-ready official verification dossier.

- 🎓 **Personalized "My Learning" Hub (`/my-learning`)**:
  - Live enrolled courses counter dynamically synced to the top navbar.
  - Interactive "Advance Progress (+25%)" button to simulate completing lectures and projects.
  - Automatic certificate unlocking upon reaching 100% completion.

- 🛡️ **Dedicated Executive Admin Studio (`/admin`)**:
  - **Overview**: Real-time revenue analytics (`₹84,52,430.50`), active courses counter, growth charts, and AI insights.
  - **Catalog Controls (`/admin/courses`)**: Live search, category filtering, "Add New Course" modal, and deletion.
  - **User Directory & Enrollment Inspector (`/admin/users`)**: Click "View Enrolled" to open an interactive modal displaying any student's courses and progress bars.
  - **AI Course Architect**: Generate complete 4-week curricula on any topic with one click.

- 🔐 **Dual-Mode Authentication Portal (`/login`)**:
  - Separate tabs for Learner vs. Executive Admin.
  - ⚡ 1-Click Fast Login demo buttons for instant testing.
  - Password visibility toggle and input validation.

## ⚡ Quick Start

### 1. Clone the Repository
```bash
git clone https://github.com/jithendarramagiri/EduLearn-Online-Course-Learning-Platform.git
cd EduLearn-Online-Course-Learning-Platform
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Application

#### Option A: Run Full Application (Frontend + Backend)
```bash
npm start
```
- **Frontend App**: [http://localhost:5173](http://localhost:5173)
- **Backend API**: [http://localhost:5000](http://localhost:5000)

#### Option B: Run Frontend Only (Offline Data Layer Active)
```bash
npm run dev
```
